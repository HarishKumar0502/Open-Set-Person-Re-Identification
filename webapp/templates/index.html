Each person is labelled with an enrolled Market-1501 identity or UNKNOWN. Defaults are calibrated on held-out identities for ≈5% unknown false-accept rate (see reports/open_set_evaluation.json). Cosine scores are not probabilities.

Video: detect, track and identify people

YOLOv8n finds people → ByteTrack links boxes into tracks (a track ID is temporary, not an identity) → a few crops per track are embedded with the ResNet18 Re-ID model → each crop is matched with the open-set rule → the track's label is a vote over its recent crops. Nothing is ever added to the gallery.
